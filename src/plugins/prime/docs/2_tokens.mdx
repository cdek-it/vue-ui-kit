# Токены

Дизайн-токены подключаются через `getPrimeVueConfig()` из `@cdek-it/vue-ui-kit` и публикуются как CSS-переменные с префиксом `--p-`.

Примеры ниже не придуманы вручную: это реальные имена CSS-переменных, автоматически полученные из путей в `src/plugins/prime/theme3.0/tokens.json`.

Внутри `Extra*`-компонентов сначала используйте component-level переменные (`--p-inputtext-*`, `--p-toast-*`), если нужный токен уже определён для компонента. Для пользовательской разметки wrapper-слоя используйте семантические переменные `color`, `dimension`, `effects` и `fonts`.

## Основные семейства

| Семейство | Пример | Источник в `tokens.json` | Назначение |
| --- | --- | --- | --- |
| Цвет текста | `--p-color-fg-default` | `semantic.colorScheme.(light\|dark).color.fg.default` | Основной текст |
| Цвет фона | `--p-color-bg-surface-canvas-default` | `semantic.colorScheme.(light\|dark).color.bg.surface.canvas.default` | Фон страницы |
| Цвет границы | `--p-color-border-neutral-default` | `semantic.colorScheme.(light\|dark).color.border.neutral.default` | Нейтральная граница |
| Отступ | `--p-dimension-space-400` | `semantic.dimension.space.400` | Семантический spacing |
| Скругление | `--p-dimension-border-radius-200` | `semantic.dimension.borderRadius.200` | Семантический radius |
| Прозрачность | `--p-effects-opacity-50` | `semantic.effects.opacity.50` | Состояние disabled |
| Типографика | `--p-fonts-font-size-300` | `primitive.fonts.fontSize.300` | Размер шрифта |
| Компонент | `--p-inputtext-border-color` | `components.inputtext.root.borderColor` | Токен конкретного компонента |

| Задача | CSS-переменная |
| --- | --- |

```css dark
.card {
  color: var(--p-color-fg-default);
  background: var(--p-color-bg-surface-raised-default);

  color: var(--p-color-fg-muted);

```

## Tailwind

`tailwindConfigTheme` экспортирует короткие алиасы для часто используемых семантических токенов.

| Tailwind-класс | CSS-переменная |
| --- | --- |
| `bg-surface-ground` | `--p-color-bg-surface-canvas-default` |
| `bg-surface-overlay` | `--p-color-bg-surface-overlay-default` |
| `bg-surface-section` | `--p-color-bg-surface-default-active` |
| `bg-surface-hover` | `--p-color-bg-surface-canvas-hover` |
| `border-surface-border` | `--p-color-border-neutral-default` |
| `text-color-primary` | `--p-color-fg-inverse-default` |
| `text-color-secondary` | `--p-color-fg-subtle` |

Severity-алиасы `info`, `success`, `warning`, `danger` и `help` используют соответствующие `--p-color-bg-status-*-strong-hover` токены.

Полный список алиасов приведён на странице [Tailwind](?path=/docs/prime-tailwind--docs).

## Формирование имени

Имя CSS-переменной строится из пути токена в `tokens.json` в kebab-case. Служебные сегменты `primitive`, `semantic`, `components`, `colorScheme`, `light`, `dark`, `root`, `states` и `extend` в итоговое имя не входят.

Например, генератор берёт путь `components.inputtext.root.borderColor`, переводит сегменты в kebab-case и отбрасывает служебный `root`, поэтому получается `--p-inputtext-border-color`.

| Путь в `tokens.json` | CSS-переменная |
| --- | --- |
| `semantic.colorScheme.light.color.fg.default` | `--p-color-fg-default` |
| `semantic.dimension.space.400` | `--p-dimension-space-400` |
| `components.inputtext.root.borderColor` | `--p-inputtext-border-color` |
| `components.inputtext.extend.iconSize` | `--p-inputtext-icon-size` |
| `primitive.colors.solid.zinc.300` | `--p-colors-solid-zinc-300` |

Сегмент `extend` отсутствует в CSS-переменной: запись `--p-inputtext-extend-icon-size` не разрешится.

## Правила использования

1. Для `skin/state/size` самого Prime-компонента сначала ищите component-level токен `--p-<component>-*`.
2. Для общей разметки wrapper-слоя (`label`, `caption`, `meta`, `gap`, контейнерный layout) используйте семантические `color`, `dimension`, `effects` и `fonts`.
3. Primitive-токены (`--p-colors-*`) напрямую в `Extra*` не используйте.
4. Не подставляйте статические значения вместо существующего токена.
5. Базу токенов, приходящую из Figma, не меняйте ради локальной wrapper-задачи: используйте уже существующие токены темы.
6. Если подходящего токена нет, сначала подтвердите это по `tokens.json` и итоговому CSS, и только потом оставляйте literal как осознанное исключение.
7. После изменения токенов или wrapper-стилей запускайте `yarn -s build-storybook` и `yarn -s check:css-vars`.

### Примеры выбора уровня токена

```css dark
/* component-level: skin конкретного input */
.extra-inputtext :deep(.p-inputtext) {
  border-color: var(--p-inputtext-border-color);
  box-shadow: 0 0 0 var(--p-inputtext-focus-ring-width)
    var(--p-inputtext-focus-ring-color);
}

/* semantic: собственная разметка wrapper */
.extra-inputtext__meta {
  margin-top: var(--p-dimension-space-100);
  color: var(--p-color-fg-muted);
  font-size: var(--p-fonts-font-size-200);
}
```
